## なぜ変えるか

SPEC-NTA-GET-TAX-ANSWER-018 は「記事の URL を国税庁の索引で決めるとき（SPEC-NTA-GET-TAX-ANSWER-016）」の規則である。018 の「例（壊れた表の DB）」では、1 回目の呼び出しで記事 6101 が国税庁サイトから取られ、`document` に書き戻される（SPEC-NTA-GET-TAX-ANSWER-006）。そのため、同じ番号で 2 回目を呼ぶと、記事は DB から返り（SPEC-NTA-GET-TAX-ANSWER-004）、索引を引かない。2 回目は 018 の前提に入らないので、最後の箇条書き「同じ DB でもう一度呼ぶと、同じく索引を条件なしで取り、同じ 2 行の `warn` を出す」のとおりにはならない。

018 と 016 の本文どうしは食い違っておらず、書き落としているのは例の 1 行の前提だけである。0.25.0 の受入テスト（`src/tools/spec-20261004-db-location.test.ts` の 018 の 2 つ目の it）は、2 回目の前に `document` の 6101 の行を消して確かめている。この差分は、例の文をそのテストと同じ前提に揃える。仕様 ID は足さず、変えない。
